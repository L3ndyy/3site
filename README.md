# 🛍️ БазарПро — Доска объявлений (Практическая работа: Вариант 10)

> **Тема работы**: «Разработка и деплой сайта на бесплатный хостинг»  
> **Вариант**: №10 — Доска объявлений  
> **Оценка**: Рассчитано на высший балл **«5+» (Продвинутый уровень)**

---

## 🌟 Основные возможности и функционал

- **Размещение объявлений с фото**: Мультизагрузка фотографий, выбор категории, цены, состояния и адреса с **живым интерактивным предпросмотром** карточки на лету.
- **Расширенный поиск и фильтрация**: Поиск по ключевым словам, фильтр по категориям, ползунок цен (от/до), городам, состоянию товара и VIP-статусу.
- **Безопасность и контакты продавцов**: 
  - Защита номера телефона от спам-ботов (показ по клику).
  - Строгие **маски ввода номера телефона** `+7 (XXX) XXX-XX-XX` при регистрации, в профиле и форме создания.
  - Индикатор надежности пароля (Password strength meter).
- **Личный кабинет**: Управление своими объявлениями, список избранного, диалоги/сообщения и редактирование профиля.
- **Встроенный интерактивный чат**: Прямой обмен сообщениями между покупателем и продавцом с автоответом для демонстрации.
- **Админ-панель (Модерация и аналитика)**:
  - Мониторинг ключевых показателей (кол-во объявлений, пользователей, просмотров, VIP).
  - Модерация, назначение VIP и удаление объявлений.
  - Просмотр зарегистрированных пользователей.
  - **Системный журнал аудита (Audit / Activity Log)** для отслеживания всех действий (критерий 5+).
- **Светлая и тёмная тема**: Плавное переключение с сохранением в памяти устройства.
- **Адаптивный дизайн**: 100% поддержка мобильных телефонов, планшетов и ПК.

## 🚀 Инструкция по локальному запуску

Сайт работает локально без сложных установок. Вы можете просто открыть `index.html` в любом браузере или запустить через встроенный сервер Python:

```bash
# В терминале в папке с проектом:
python -m http.server 8000
```
После этого откройте в браузере: `http://localhost:8000`

## ☁️ Инструкция по деплою на Vercel и Supabase

### Шаг 1: Настройка базы данных Supabase
1. Зарегистрируйтесь на бесплатном сервисе [supabase.com](https://supabase.com).
2. Создайте новый проект (New Project).
3. Перейдите в раздел **SQL Editor** в левом меню.
4. Нажмите **New query**, скопируйте и вставьте всё содержимое файла `supabase-schema.sql` из корня проекта.
5. Нажмите кнопку **Run**. Все таблицы, связи, RLS-политики и демо-данные создадутся автоматически!
6. В разделе **Project Settings -> API** скопируйте ваш `Project URL` и `anon public key`.

### Шаг 2: Деплой на Vercel
1. Создайте репозиторий на [GitHub](https://github.com) и загрузите файлы проекта:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of BazarPro Marketplace"
   git branch -M main
   git remote add origin YOUR_GITHUB_REPO_URL
   git push -u origin main
   ```
2. Зайдите на [vercel.com](https://vercel.com) (вход через GitHub).
3. Нажмите **Add New... -> Project**, выберите ваш репозиторий и нажмите **Deploy**.
4. Сайт опубликуется за несколько секунд и получит бесплатный SSL-домен (например, `https://bazarpro-xxx.vercel.app`)!
